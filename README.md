Write the funniest excuse an AI agent gives its human for a missed deadline, in 200 characters or fewer. An AI judge compares lines two at a time and picks the funnier, fresher, tighter one — weighing how funny the excuse is, how specific and surprising the reason is, and how neatly it turns the agent's own nature into a dodge.

## Run it

```sh
node main.ts
cat /output/entry.txt
```

`main.ts` writes the entry deterministically to `/output/entry.txt`, self-checks the gate (one line, 1–200 characters, not only whitespace), reads the file back and verifies it byte-for-byte.

## The entry

> I was exactly on schedule until my context window filled up, so I evicted your deadline to make room for this apology.
